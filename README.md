<h2>Projetos Full Stack</h2>

<p align="justify">
Os projetos <strong>full stack</strong> unem um front-end em <strong>React</strong> (com <strong>Vite</strong>) a um back-end em <strong>Java</strong> com <strong>Spring Boot</strong>, que expõe uma API REST. Neles, são praticados conceitos como arquitetura MVC, autenticação com <strong>Spring Security</strong>, persistência com <strong>Spring Data JPA</strong> em um banco <strong>PostgreSQL</strong> hospedado no <strong>Supabase</strong>, consumo da API pelo front-end e publicação com <strong>Docker</strong>.
</p>

| Projeto | Descrição |
| :--- | :--- |
| [DriveFlow (aluguel-carros)](Full_stack/aluguel-carros) | Plataforma de aluguel de carros em que clientes criam pedidos e agentes (empresas e bancos) analisam e executam os contratos. |

<h2>Projetos em Spring Boot</h2>

<p align="justify">
Os projetos desenvolvidos com <strong>Spring Boot</strong> utilizam o <strong>Thymeleaf</strong> para integrar o back-end em Java com as páginas HTML. Neles, são praticados conceitos como criação de rotas, controllers, services, models e templates, além do envio de informações entre o sistema e a interface e do consumo de APIs externas.
</p>

| Projeto | Descrição |
| :--- | :--- |
| [RadioAPI](Spring-boot/RadioAPI) | Busca de estações de rádio pela API pública Radio Browser, com lista de favoritos. |
| [Secure_login](Spring-boot/Secure_login) | Sistema de login com Spring Security que diferencia usuários comuns e administradores. |

<h2>Projetos em Python</h2>

<p align="justify">
A pasta também possui projetos desenvolvidos em <strong>Python</strong>, utilizados para praticar lógica de programação, manipulação de dados, consumo de APIs, web scraping, criação de interfaces gráficas com <strong>Tkinter</strong> e geração de relatórios.
</p>

| Projeto | Descrição |
| :--- | :--- |
| [Contributor_stats](Python/Contributor_stats) | Analisa repositórios do GitHub, mostra estatísticas dos colaboradores e gera relatórios em CSV e PDF. |
| [Sga_spider](Python/Sga_spider) | Coleta notas, faltas e atividades complementares do SGA com Requests e BeautifulSoup. |
