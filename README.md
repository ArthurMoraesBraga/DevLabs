<h1>DevLabs</h1>

<p>
O <strong>DevLabs</strong> é uma pasta destinada ao armazenamento de projetos, atividades práticas e testes desenvolvidos durante meus estudos de programação.
</p>

</div>

<h2>Projetos em Spring Boot</h2>

<p align="justify">
Os projetos desenvolvidos com <strong>Spring Boot</strong> utilizam o <strong>Thymeleaf</strong> para integrar o back-end em Java com as páginas HTML. Neles, são praticados conceitos como criação de rotas, controllers, services, models e templates, além do envio de informações entre o sistema e a interface. Esses projetos têm como objetivo compreender o funcionamento de aplicações web e a organização das diferentes partes de um sistema.
</p>

<h2>Projetos em Python</h2>

<p align="justify">
A pasta também possui projetos desenvolvidos em <strong>Python</strong>, utilizados para praticar lógica de programação, manipulação de dados, criação de scripts e utilização de bibliotecas. Esses projetos ajudam no desenvolvimento do raciocínio lógico e no aprendizado de diferentes possibilidades oferecidas pela linguagem.
</p>
